# 🚀 来一发 / FlowPost

写一次内容，分发到多个平台。

FlowPost 是一个本地浏览器插件。你写好文案，放好图片，它会帮你把内容填到多个平台的发布框里。默认只填充草稿，不直接发布，最后一步仍然由你检查。

现在支持：

- 即刻
- X / Twitter
- 小红书
- 抖音
- 视频号
- 观猹
- Substack Notes
- LinkedIn

它不会保存你的平台账号密码，也没有后端。它只是打开网页，用你当前浏览器已经登录好的账号去填发布框。

![FlowPost 界面](https://pbs.twimg.com/media/HJc-AKKaEAEzUmS?format=jpg&name=4096x4096)

## 🤯 为什么做它

多平台发布最烦的不是写内容，而是重复劳动。

- ❌ 同一段文案要复制到好几个平台。
- ❌ 图片要重复上传，还要检查顺序。
- ❌ 平台页面一多，标签页乱成一团。
- ❌ 自动发布风险高，但纯手动又太慢。

FlowPost 的思路很克制：帮你把内容填好，停在发布前，让你最后确认。

## 🎯 它适合什么场景

- 一段内容要同步发到即刻、X、小红书、抖音、视频号、观猹、Substack Notes、LinkedIn。
- 有图文内容，需要最多 9 张图片一起处理。
- 想保留人工检查，不想让插件直接接管发布。
- 经常跨平台发相同内容，想减少复制、粘贴、开页面的机械动作。

## 💡 核心功能

- ✅ 文案输入和本地草稿保存。
- ✅ 最多 9 张图片，支持粘贴、点击放大和拖动排序；超过 4MB 会在本地自动优化。
- ✅ 可隐藏暂时不用的平台，并随时一键恢复。
- ✅ 平台卡片使用各平台官方 Logo，并随插件本地打包。
- ✅ 扩充即刻常用圈子，并支持搜索或手动输入圈子名称。
- ✅ 小红书图文模式先上传图片，再填入标题和正文。
- ✅ 多平台发布页自动打开。
- ✅ 多平台标签页自动分组。
- ✅ 单个平台重试时回到原分发分组，不重复新建分组。
- ✅ 区分「填充成功」与「发布成功」；发布成功需要你确认。
- ✅ 默认填充草稿，停在发布前。
- ✅ 可尝试自动发布，但属于实验功能。
- ✅ 本地任务日志，方便查看哪个平台成功、哪个需要手动处理。

## 🧩 安装方式

如果你只是使用插件，优先用 Release 压缩包，不用命令行。

1. 打开 GitHub Releases 页面：

```text
https://github.com/kanshao2077/Flowpost/releases
```

2. 下载最新版本里的 zip 文件，例如：

```text
flowpost-0.1.6-chrome.zip
```

3. 解压这个 zip。
4. 打开 Chrome 或 Edge：`chrome://extensions/`
5. 打开右上角「开发者模式」。
6. 点击「加载已解压的扩展程序」。
7. 选择刚刚解压出来的文件夹。

注意：浏览器加载的是“解压后的文件夹”，不是 zip 文件本身。

## 🛠️ 用源码安装

如果 Release 没有 zip，或者你想自己构建，再用这个方法。

先安装 Node.js LTS 和 Git，然后运行：

```bash
git clone https://github.com/kanshao2077/Flowpost.git
cd Flowpost
npm install
npm run build
```

构建完成后，会出现这个文件夹：

```text
.output/chrome-mv3
```

然后打开 `chrome://extensions/`，加载 `.output/chrome-mv3`。

注意：选的是 `.output/chrome-mv3` 这个文件夹，不是整个项目文件夹。

## ⚙️ 怎么使用

1. 先在浏览器里登录好即刻、X、小红书、抖音、视频号、观猹、Substack、LinkedIn。
2. 点击浏览器右上角的「来一发」插件图标。
3. 在文案框里输入内容。
4. 粘贴图片，或者点击图片区域选择图片。
5. 需要多图时，最多 9 张，可以拖动缩略图排序。
6. 选择要分发的平台。
7. 如果选了即刻，记得选择圈子。
8. 建议先用「填充草稿」模式。
9. 点击「开始分发」。

FlowPost 会打开各个平台的发布页，并把这些标签页放进同一个浏览器标签组里。处理完后，可以直接关闭整个标签组。

小红书当前只适配「上传图文」：至少添加 1 张图片，第一段作为标题，其余内容作为正文；如果只有一段，正文保留原文。视频、文字配图、长文和播客暂不处理。

## 🧠 两种发布模式

### 填充草稿

默认模式。FlowPost 只负责把文字和图片填进去，不帮你点发布。

这个模式最稳，适合日常使用。

### 尝试自动发布

FlowPost 会尝试点击发布按钮。

这个功能是实验性的。点击按钮不等于已经公开发布；确认平台页面发布成功后，再回到日志点击「确认已发布」。小红书、抖音、视频号和观猹仍固定停在发布前。

## ❓ 常见问题

### 未登录怎么办

如果某个平台没有登录，日志会提示你先登录。

处理方式：

1. 在 FlowPost 打开的那个平台标签页里登录账号。
2. 登录成功后回到 FlowPost。
3. 再点一次「开始分发」。

FlowPost 不保存账号密码。登录状态是浏览器自己的。

### 为什么加载插件时找不到 `.output/chrome-mv3`

你还没构建。执行：

```bash
npm run build
```

### Release 压缩包和源码有什么区别

Release 压缩包是已经构建好的插件。

```text
下载 zip -> 解压 -> Chrome 加载解压后的文件夹
```

源码是给开发和修改用的。

```text
git clone -> npm install -> npm run build -> Chrome 加载 .output/chrome-mv3
```

如果只是换电脑使用，优先用 Release 压缩包。

### 为什么平台页面打开了，但是没有填进去

通常是三种情况：

1. 你还没登录该平台。
2. 平台页面加载太慢。
3. 平台改版了，原来的页面选择器失效。

先登录，再重试。如果还是不行，就需要更新适配逻辑。

### 怎么检查文案排版有没有变

先用「填充草稿」测试，不要一上来自动发布。

建议拿这种文案试一下：

```text
冷知识：
我五点之后就干不动了开始摸鱼了。

我实在看不懂那些加班加出斗志的打工人是什么心态。

https://example.com
🙂
```

打开各个平台后，看发布框里的换行、空行、链接和 emoji 是否和 FlowPost 输入框一致。

一致，再手动发布。不一致，就先别发，说明这个平台的页面适配需要继续修。

## 💾 本地保存和隐私

FlowPost 没有后端。

本地会保存：

- 文案草稿
- 图片数据
- 平台选择
- 隐藏的平台
- 即刻圈子
- 最近一次任务日志

不会保存：

- 平台账号
- 平台密码
- 登录验证码
- 平台访问令牌

```bash
npm run zip
```

```text
.output/flowpost-0.1.6-chrome.zip
```

## 🧩 项目结构

```text
entrypoints/options      插件主界面
entrypoints/background   打开标签页、任务调度、标签分组
entrypoints/content      注入到平台页面的脚本入口
src/adapters             各平台发布框适配
src/shared               共享类型、平台配置、本地存储
public/icons             插件图标
```
